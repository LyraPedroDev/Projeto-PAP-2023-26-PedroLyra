# EcoChat Frontend

Este diretório contém a interface do EcoChat construída com React, TypeScript e Vite.

## O que existe aqui

- autenticação e navegação principal
- feed social
- ranking
- missões
- amigos
- perfil
- mensagens privadas
- área administrativa

## Estrutura principal

```text
frontend/
├── src/
│   ├── components/
│   ├── services/
│   ├── styles/
│   ├── App.tsx
│   └── main.tsx
├── public/
├── package.json
└── vite.config.ts
```
